# 章法 0.3：让中文网页，有自己的章法

AI 做的中文网页，有时远看挺像样，认真读就露馅。

“为什么”断成“为什／么”，一个“选”单独站一行；电脑上的大标题，到了手机把按钮和说明挤成碎片。更难的是：修好这几行字之后，整页仍然没有自己的重心。

我做了「章法」：一套面向 Codex、Claude Code 的中文网页设计与验收 Skill。给它真实中文，先梳理读者来这一页要做什么，再安排信息、排印和视觉主体；接上我之前做的「分寸」，在浏览器里测量、操作、复看。

从零做页、保留功能改好旧页、交付前只审不改，分别有自己的做法和完成依据。

这次把自己的展示站也重新打磨了一遍，保留作品画廊的气质，让案例更容易看明白：

- **一组完整页面对比。** 同样的纸岸书店内容，看书籍如何成为首屏主对象，日程如何接住行动，手机如何重新排布。完整书名、价格、条件和报名演示都保留。
- **五组同页修订。** 同一窗口切换前后，让“为什么”完整地问，把孤零零的“选”放回句子；完整截图与页面均可打开。
- **把状态说清楚。** 原始生成与后期修订、技术检查与模型视觉审查、人工和真机待验，分别呈现。

技能也补上了更具体的执行约定：开始时说明主任务和保留项，方向探索留下真实片段，交付时核对实际运行结果。已选方向不必重新走多选流程，没做的检查不能写成通过。

这些是精选案例，包含后期审查修订，不代表首次生成胜率；冷启动行为验证也只说明具体任务表现，不能证明所有模型都稳定执行或达到行业领先。原始对照、历史产物和失败记录都保留，真实手机与真人阅读体验仍单独待验。

中文网页的好看，不只是一套字体和配色。让内容决定结构，让文字读得自然，让操作接得上，才是我想持续打磨的章法。
