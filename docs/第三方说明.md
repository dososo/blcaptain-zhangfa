# 第三方说明

## 运行依赖

| 依赖 | 固定开发版本 | 用途 | 许可与分发方式 |
|---|---|---|---|
| measure-cjk | 0.1.0 | 中文排版测量与字体许可查询 | 代码 Apache-2.0；文档与授权数据 CC BY 4.0。通过 npm 独立安装，不将包或字体复制进技能归档 |

## 字体与图像

示例优先使用系统字体栈与原创 HTML/CSS/SVG。仓库不包含第三方字体文件，系统字体只由访问者设备调用。没有经过核验的素材不作为真实摄影、产品照片或历史作品出现。

内部研究截图、上游样张与源文件不进入技能归档或公开案例资产。实际增加素材时，逐项记录来源、许可、版本、归属要求和使用范围。

## 原创内容

技能、检测器、案例内容与展示站在本项目内独立编写。最终技能正文不包含研究对象、上游命令体系或风格库。方法是可检查的设计流程，不宣称独占一般设计原则。
