## 完整案例的性质

从原24场景中精选05纸岸书店。两侧是相同冻结任务下的不同生成条件：无本技能的原始产物与章法＋分寸的修订产物，后者包含0.2.0后期视觉修订。它不是同一页改版前后，也不是0.3.0首次生成结果，不据此计算胜率或转化。

1440px完整截图：对照页2341px高、修订页1567px高；390px分别2694px与2853px高。尺寸如实保留，手机修订页略长是重排的代价，不宣传“全平台都更短”。全页截图不包含默认关闭的报名说明；相关内容另以真实操作验证。

对比页允许查看桌面和手机完整截图；切换条件按比例保留纵向位置。结构不同意味着内容锚点不一一对应，因此另提供实际页面、完整原图和首次章法生成页入口。

## 执行稳定性改进

技能入口保持精炼，新增三模式最小证据和开工/结束核对。结构未知时探索两到三个可回看的真实方向，已定方向或局部修复可合理简化；不以事后描述冒充产物。缺浏览器、未执行检查或修后沿用旧证据均须披露。提示、实际接受输入、失败反馈与结果需要一致。

本轮另用隔离冷启动新建任务观察执行行为。独立审阅发现320px结果标题的“了。”孤行，说明执行者自测仍有遗漏；修复与复查单列，未补记成首次成功。由此补充最窄受支持宽度也要实际触发主任务结果的指引；这条补充发生在该次冷启动之后，不能反称已在该任务中预先得到验证。一次任务只能验证具体表现，不证明跨模型稳定性、统计胜率或SOTA。人类审美、真实设备、完整无障碍和跨平台字体仍待独立验收。

## 分寸规则与画廊取舍

主站保留展示字号的局部负字距、12px章节索引/辅助元信息、标题试排1.4行高；完整案例页保留品牌与大标题的局部负字距。这些会触发默认分寸的T07/T11/T06，不是规则零错误页面。它们用于短展示文字，正文与主要动作使用独立阅读约束，未关闭规则或改阈值。模型视觉审查判断与原始规则结果分别记录，异常不能因审美理由被悄悄换成通过。

已处理新案例中文字体栈缺项、正文过长与混排声明；主站重要说明提高字号并限制长段行宽。最终余项以实际复测记录为准。

## 假设与未覆盖

- 本轮实现和浏览器证据主要来自macOS与Chrome；窄屏模拟不等于真机。
- 作品与业务内容均为合成演示；没有真实订单、报名或业务提升数据。
- 画廊风格和展示顺序是设计判断，需要队长最终人工验收。
- 模型独立审阅与真实人类盲评分别记录；后者仍为 `MANUAL_PENDING`。
- 技能只在有限任务与当前工具环境验证；不同模型和预算可能省略步骤，执行约定不能保证遵循。

## 最小回滚

展示站恢复本轮 `site/index.html`、`gallery.css`、`gallery.js`、`style.css`、`app.js`的对应改动，并撤下新增完整案例入口即可恢复上一版主流程；原对照和历史页无需恢复。技能回滚恢复入口、验收协议与检查器本轮增量。整版可重新部署v0.2.0；新增证据保留，不批量删除文件。
