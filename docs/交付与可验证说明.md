# 章法首版交付与可验证说明

日期：2026-10-29。版本：0.1.0。

## 一、需求拆成哪些可检查行为

| 行为 | 文件与组件 | 验证依据 |
|---|---|---|
| 智能体按中文任务创建、受限改版或只审阅 | `skills/blcaptain-zhangfa/SKILL.md` 与三个参考 | 技能结构校验；实际项目目录中的Codex与Claude Code发现/加载 |
| 中文实际行片段进入布局判断 | `scripts/check-page.mjs` 中 `headingLines` | 浏览器Range取得前12个可见横排标题；真实行片段、竖排不占额度回归 |
| 资源或环境失败不会假通过 | 同脚本 `inspectWidth`、`measure`、`inspectPage` | 404与断连、浏览器缺失、分寸缺失/版本异常/配置冲突、资源阻断回归 |
| 原始证据不会被下一次检查覆盖 | 同脚本独立 `run-*` 与 `measure-*` 目录 | 重复运行保留旧截图与旧报告回归 |
| 技能脱离源码目录仍可安装使用 | `scripts/package.mjs` 与ZIP安装测试 | 固定时间/顺序的可重现归档；独立目录运行、依赖从调用项目解析 |
| 24场景可查看三种条件 | `site/cases.json`、`site/runs/`、`site/app.js` | 60页面、12审阅报告的实际文件与摘要；模式、条件和证据入口 |
| 局部中文问题可动手试排 | `site/lab/` | 12组同文案有限变量示意；视口、焦点、失败与恢复操作 |
| 改版和只审阅保护原输入 | `bench/inputs/`、`input-manifest.json` | 固定输入摘要；13订单数据、字段、路由、焦点及错误恢复记录 |

## 二、执行了哪些命令

```bash
npm test
npm run verify
npm run pack:skill
python3 <skill-creator目录>/scripts/quick_validate.py skills/blcaptain-zhangfa
node scripts/qa-showcase.mjs <待检查题号>
```

测试覆盖本地服务器、技能包、独立安装、检查器、只审阅输入、展示站和12组局部示意。包结构验证与浏览器行为测试分别记录，不把结构校验当审美证明。

60个实施页面另经320、390、1440像素的独立自动复查。38页通过所测自动规则，22页保留失败：20页为未加载分寸的对照条件，另两页为16题在320px时的状态分隔点触发T04。这个计数衡量所测规则，不衡量视觉胜率。每题原始生成记录包含作者执行的主任务、压力检查、额外修复与未覆盖范围；脱敏副本在展示站 `records/runs/`。作者自测不冒充独立人类评测。

## 三、来自推断与需要确认的内容

- “OK”按上一轮首推名称与推荐路线接受，采用 `blcaptain-zhangfa「章法」`。
- 示例里的品牌、机构、人物、价格和业务数据为冻结的合成演示，不对应真实客户。
- 字体栈、语义断行和视觉风格需要场景判断；没有把系统字体或渐变天然判错。
- 完整模型构建号与所有模型成本没有统一暴露，因此不报告严格实验胜率。

## 四、仍未覆盖或存在的限制

- 真人盲评、连续阅读体验、真实手机、完整读屏与跨浏览器验收：`MANUAL_PENDING`。
- 浏览器自动检查不覆盖全部无障碍、懒加载、动态业务状态和每个字的实际字体来源。
- 部分章法样例未完整执行先片段试排与多方向比较；额外修复也存在，已在条件内披露。这批是探索示例，不是完整流程严格对照。
- 开发样例中仍有标题短语跨行风险。独立320px复查还在16题的仅分寸与章法条件中发现行首状态分隔点触发T04，保留失败，等待人工仲裁，不关闭规则凑通过。
- 最终技能根据开发反馈增加标题行片段与流程偏差披露，示例并非全部由最终同一版本生成；旧入口快照保存在 `bench/skill-snapshots/`。

## 五、宿主兼容性实测

| 宿主 | 实测 | 边界 |
|---|---|---|
| Codex CLI 0.154.0 | 临时项目从ZIP解压到 `.agents/skills/`；实际读取目标技能入口并正确返回三模式与未运行状态 | 宿主仍可扫描其现有技能；不能把测试说成清空所有全局能力的模型基准 |
| Claude Code 2.1.296普通运行 | 同一临时项目 `.claude/skills/`；Skill工具实际返回加载成功，继续读取验收参考 | 仅开放Read/Skill、禁写入与代码工具；关闭钩子与其他MCP，未改全局配置 |
| Claude Code限制模式 | 工具返回Unknown skill，随后只能直接读文件 | 不算技能发现通过；普通运行加载成功不代表所有限制模式均支持 |

原始宿主运行记录保留本地，未将含本机路径的会话原文公开。

## 六、最小回滚

- 使用者只需把自己安装的 `blcaptain-zhangfa` 目录移出相应技能目录。技能本身不修改全局工具配置。
- 网页改版根据当次diff逐文件恢复；不删除用户目录或其他技能。
- 本项目回退到已验证Git提交或版本包；保留失败证据，不通过删记录恢复“全绿”。
