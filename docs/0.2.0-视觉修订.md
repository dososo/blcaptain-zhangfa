# 章法 0.2.0 视觉修订记录

日期：2026-10-29。范围：章法条件页面、展示站、技能与宣传文档。原始生成历史保留，另外两组对照及冻结输入不修改。

## 这一轮改变了什么

章法的展示需要同时经得起第一眼和认真看。第二轮从真实页面出发，独立审查 20 个实施页的 320、390、768、1440 像素表现，针对其中 13 页处理中文断行、中宽拥挤、图示文字和动态反馈问题，再把共性决定补入技能。

展示站改为先看作品、再看同页修订，最后进入三条件试验场。原有搜索、条件切换、宽度预览、独立页面与局部试排继续保留。

修复页面为 01、05、06、07、08、09、14、16、17、19、20、21、22；未因追求变化重做所有页面。

## 技能内化了哪些判断

入口仍为六步与三种模式，详细内容放在三个按需参考中：

- 断行先调整容器与排列，再处理少量语义片段和字号；均衡换行不能保证中文语义自然。
- 窄屏按内容重排；必要二维内容局部滚动，完整信息、阅读与操作顺序分别检查。
- 视觉审查覆盖真实截图中的主对象、路径、密度与整体节奏；机器通过和设计意见分开。
- 除前 12 个可见横排 `h1/h2`，另按任务采样主动作、导航、图示标注和动态反馈。
- 320 CSS 像素重排、200%文字放大、文字间距覆盖、字体和资源失败分别记录，工具未执行的项目保持未知或未运行。
- 原始生成、后期审查修复、精选推广与手工示意分别标注。

## 新增阅读压力与默认覆盖

20页在320／390px分别执行文字间距覆盖与初始计算字号逐元素翻倍，共80个压力状态。初次发现19题长不换行片段造成40px根溢出，同时清单编号与正文挤压；已修复，80状态复查无根溢出或所查控件越界。这是CSS压力测试，不代表真实浏览器缩放。

展示站另在真实Chrome的200%浏览器缩放下实际查看首屏，完成场景筛选及键盘激活切换，然后恢复100%。该次仅覆盖展示站，不扩大为全部案例200%验收。检查器默认加入320px，七宽覆盖包括320、360、390、768、1024、1280、1440；新增失败回归验证其实际执行。
