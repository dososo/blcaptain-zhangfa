# 章法的方法与边界

章法从真实中文内容与访客任务出发，组织页面结构、中文构成、视觉主对象和交互反馈，再以浏览器结果与独立审阅验证。

## 六步方法

| 步骤 | 输入 | 可检查的输出 |
|---|---|---|
| 明事 | 受众、任务、内容与限制 | 真实资料、演示数据、假设和缺失项分开 |
| 成章 | 决策顺序与现有设计 | 结构假设与选择理由；小修保持原系统 |
| 量字 | 真实中文、字体与宽度 | 文本行、边界、加载状态与分寸结果 |
| 造境 | 内容主对象 | 有信息职责的排印、图像、色彩与反馈 |
| 验真 | 当前运行页面 | 资源、布局、主任务和内容保全证据 |
| 复核 | 任务与产物 | 独立意见、机器结果、分歧与人工状态 |

## 三种使用模式

新建可以比较方向；受限改版必须先保护行为；只审阅不得写回源文件。规则数量和方案数量不是质量证明。

## 四条边界

- 中文度量不等于全部中文语义正确；断行是否自然仍需判断。
- 浏览器检查不等于完整无障碍、真实设备或生产后端验收。
- 独立模型评审不是人类用户研究。
- 示例的可见差异不是普遍胜率、业务转化或流行程度的证明。

分寸当前使用 `measure-cjk@0.1.0`。缺失依赖和未运行检查明确保留；工具不自动联网安装，不修改全局配置。

## 关于示例

展示站区分真实智能体试运行、规则示意和未制作题目。真实运行仍可能有缺陷；如果后续手工修复展示页，保留原始产物并标记修复，不能将它继续作为未经干预的生成结果。

发布只承诺已验证的能力。技术状态、视觉意见、人工验收与线上可访问状态分别记录。
